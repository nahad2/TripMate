# TripMate – Group Trip Budget & Expense Management System

## Project Overview

TripMate is a web-based application designed to simplify group trip budget management and expense sharing. It provides a centralized platform where users can create trips, manage members, track financial contributions, record shared and individual expenses, and calculate final financial settlements.

Managing money during group trips can be challenging when members contribute at different times, make additional payments, skip certain activities or meals, or pay group expenses using their personal funds. TripMate addresses these challenges through an organized and transparent financial management system.

## Key Features

- **Trip Management:** Create trips, manage destinations, dates, and group members.
- **Budget Management:** Set individual budgets and monitor the overall trip budget.
- **Contribution Tracking:** Record initial and additional payments from each member.
- **Expense Management:** Track transportation, accommodation, meals, and other expenses.
- **Flexible Expense Splitting:** Divide expenses equally or assign custom amounts based on individual participation.
- **Personal Payment Tracking:** Record expenses paid by members using their own money.
- **Reimbursement Management:** Track pending and completed payments owed to members.
- **Financial Dashboard:** Monitor total contributions, expenses, and remaining funds.
- **Final Settlement:** Automatically calculate individual balances and determine who owes money or receives a refund.
- **Report Generation:** Generate detailed financial summaries and export reports as PDF.

## Technology Stack

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap
- **Backend:** PHP
- **Database:** MySQL
- **Version Control:** Git and GitHub

## Project Objectives

The primary objective of TripMate is to make group trip financial management easier, more accurate, and transparent. It aims to reduce manual calculations, prevent confusion regarding individual contributions and expenses, and ensure proper financial settlement among group members.

## Cross-Platform Distribution

The application is planned to support the following distribution formats:

- Windows: `.exe`
- Linux: `.deb` and `.AppImage`
- macOS: `.dmg`

## Expected Outcome

TripMate will provide a reliable solution for managing group travel finances through automated calculations, organized transaction records, flexible expense sharing, personal payment tracking, and accurate final settlements.
